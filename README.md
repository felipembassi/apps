# Apps by Felipe Bassi

Support and privacy pages for Pura Sorte, Hourbee and Lunido, served by GitHub Pages at https://felipembassi.github.io/apps/.

Static HTML only: no cookies, no analytics, no third-party scripts. Each folder has an `index.html` that opens the page in the browser's language.

Edit the texts in `build.py`, then run `python3 build.py`. Never edit the generated HTML by hand.
